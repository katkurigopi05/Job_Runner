# Coverage snapshots

The dated CSV files record registry coverage research as of their filenames and
`As Of` fields. They are historical observations, not current job availability,
verified ATS support, or complete official index membership. In particular,
`fortune500_coverage_2026-11-13.csv` contains 498 recorded company rows.

`sp500_coverage_2026-10-14.csv` retains source URLs and explicit verification
statuses. `bespoke_careers.csv` is a small manual discovery fixture; homepage
URLs are starting points, not confirmed application endpoints. Import is an
explicit operator action, subject to the crawler's robots and rate-limit rules.
No browser session or credential is needed to read these files.
