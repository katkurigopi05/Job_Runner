QUEUE ARCHITECTURE

Postgres FOR UPDATE SKIP LOCKED

How the worker claims tasks exclusively without lock contention and safely recovers from mid-flight crashes.

1
SELECT ... FOR UPDATE SKIP LOCKED
Selects runnable row where status='pending' OR lease_expires_at < clock_timestamp().
2
Commit Claim Transaction
Sets locked_by=worker_id, lease_expires_at=now()+300s, attempts=attempts+1. Commits immediately so crash doesn't reset attempts.
3
Heartbeat Lease Renewal Task
_keep_lease_alive background task extends lease every 60s while Playwright drives ATS browser form.
4
Finalize State
Marks status='completed' or 'failed'. Reclaimed crashed tasks resume idempotently.
VECTOR & LEXICAL SEARCH

Dense pgvector & FTS Fusion (RRF)

Overcomes semantic drift between adjacent roles (e.g. Python vs Java) by fusing dense cosine similarity with exact BM25/FTS terms.

1
Dense Embedding Retrieval
Candidate resume vector (384d) compared against postings.embedding using pgvector cosine distance operator (<=>).
2
Lexical BM25 / FTS Search
PostgreSQL Full Text Search queries title and description with inverse document frequencies (corpus_stats).
3
Reciprocal Rank Fusion (k=60)
Score = Σ 1 / (60 + rank_i). Rank-based fusion reconciles disparate score scales without artificial weights.
TEST CONCURRENCY

Advisory Locks & Isolation

Prevents parallel pytest processes or agent sessions from destroying each other's test state in the database.

1
pg_try_advisory_lock
First pytest process takes session advisory lock (0x4A6F6252). Second process exits cleanly rather than racing.
2
Transaction Rollback Fixture
Unit tests execute inside a single transaction and rollback at teardown for speed.
3
Cascading Table Truncation
Integration tests that commit across processes clean up by truncating _ALL_TABLES with CASCADE.
